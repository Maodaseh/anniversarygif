Cloud Live Sync

Connect to a free Firebase Realtime Database so that whenever you type a message on your computer, it updates on Aseh's phone in real time without refreshing!

How to get a free Firebase URL (Takes 1 min):

1. Open console.firebase.google.com

2. Click Add project → Build → Realtime Database

3. Go to Rules tab and set ".read": true, ".write": true

4. Copy your Database URL (e.g. https://...firebaseio.com) and paste it above!
